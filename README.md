# Patent Specification Lab v0.4.1 — Assessment Record

고등학교 「지식재산일반」 수업용 AI 특허명세서 작성 보조 웹앱입니다.

## v0.4.1 핵심 변경점

- v0.3의 선택형 프리핸드 스케치 기능 유지
- 최초 발명 아이디어를 별도로 보존
- AI 확인 질문과 학생의 응답을 차시별 과정 기록으로 저장
- AI 제안 선택 / 학생 직접 입력 / 미확정 응답을 구분하여 기록
- 여러 번 AI 확인을 거쳐도 이전 응답을 다음 AI 요청에 함께 전달
- 학생이 확정한 발명 구조와 구성요소·기능을 기록
- AI가 처음 생성한 명세서 초안을 별도로 보존
- 최종 편집 단계에서 「내가 수정한 내용과 이유」 2건을 기록 가능
- 마지막 화면에서 최초 아이디어 → AI 확인 과정 → 발명 구조 → AI 최초 초안 → 수정 기록 → 학생 최종 명세서를 하나의 「수행평가 학습 기록」으로 자동 정리
- 수행평가 기록 전체 복사 및 MD/TXT 다운로드 지원
- 특정 플랫폼(Notion 등)에 종속되지 않고 LMS·디지털 포트폴리오·문서 등에 제출 가능

## 평가 설계 의도

AI가 자동 생성한 최종 결과만 평가하지 않고 학생의 입력·선택·수정 과정까지 교사가 확인할 수 있도록 설계했습니다.

## Gemini

현재 코드의 모델: `gemini-3.6-flash`

학생 본인의 Google AI Studio API Key를 브라우저에서 사용하며 Key는 `sessionStorage`에만 보관합니다.

## 주의

교육용 초안 작성 도구이며 실제 특허 출원, 등록 가능성 또는 법률적 완성도를 보장하지 않습니다.


## v0.4.1 변경사항
- 발명 구상 스케치를 선택적 과정 증거로 안내하고 최종 기록에 제출 여부를 표시합니다.
- AI 최초 명세서와 학생 최종본을 항목별로 자동 비교합니다.
- 학생이 수정 내용을 임의로 적는 대신 실제 변경된 항목을 앱이 표시하고, 학생은 의미 있는 수정의 이유를 기록합니다.
- 수정이 없으면 수행 기록에 `실질적 수정 없음`으로 명시됩니다.
- 첨부한 발명 구상 스케치를 완료 화면에서 별도 저장할 수 있습니다.
