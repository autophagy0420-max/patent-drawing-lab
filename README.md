# Patent Specification Lab v0.3 — Optional Sketch

고등학교 「지식재산일반」 수업용 특허명세서 작성 보조 웹앱입니다.

## v0.3 핵심 변경점

- STEP 1에서 **프리핸드 스케치 선택 첨부**
- JPG / PNG / WEBP 지원
- 브라우저에서 최대 1600px로 축소해 Gemini에 전달
- 스케치 미첨부 시 기존과 동일하게 `제목 + 설명 + 확인 질문`으로 진행
- 스케치 첨부 시 `제목 + 설명 + 스케치`를 함께 이해
- 스케치는 **보조 자료**로만 사용
- 설명과 스케치가 충돌하거나 그림에만 있는 구조는 AI가 확정하지 않고 학생에게 질문
- STEP 2에 `스케치에서 참고한 내용 / 설명과 스케치 사이에서 확인할 점` 표시
- 발명 구조 확정 시 `AI 제안을 참고해 구체화된 부분`, `핵심 미확정`, `선택사항` 분리
- 마지막 도면 프롬프트 작성에서도 초기 스케치를 다시 참고하여 도면 계획 생성
- 앱 자체에서는 이미지 생성 API를 호출하지 않음

## 발명 정보의 우선순위

명세서 구체화 단계:
`학생이 확인한 답변 > 학생의 텍스트 설명 > 스케치에서 관찰된 내용 > AI 추론`

도면 프롬프트 단계:
`학생 손스케치 > 학생이 확정한 구조 > 명세서 기능 설명 > AI 추론`

## Gemini

현재 코드의 모델:

`gemini-3.6-flash`

학생 본인의 Google AI Studio API Key를 브라우저에서 사용하며 Key는 `sessionStorage`에만 보관합니다.

## 배포

일반 Vite 프로젝트입니다.

```bash
npm install
npm run dev
```

GitHub에 업로드한 뒤 Vercel에서 Vite 프로젝트로 Import/Deploy 하면 됩니다.

## 주의

교육용 초안 작성 도구이며 실제 특허 출원, 등록 가능성 또는 법률적 완성도를 보장하지 않습니다.
